# Changelog

Todas as mudanças relevantes deste projeto serão documentadas neste arquivo.

O formato segue a intenção do Conventional Commits usado no Boilerplate-vue.

## 0.1.0

### Features

- Refatoração inicial do backend para `Boilerplate-java`.
- Núcleo com autenticação JWT, recuperação de senha por OTP, login com Google e solicitação de acesso.
- Modelagem inicial de usuários, cargos, permissões RBAC, OTP, refresh tokens, solicitações de acesso e logs de erro.
- Motor de filtros e paginação por cursor compatível com os contratos do frontend.
- Migrations Flyway limpas para novos projetos.
- Versionamento Maven baseado em Git com jgitver.
